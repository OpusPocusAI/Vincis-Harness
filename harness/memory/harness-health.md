# Harness Health Dashboard

Sprint-over-sprint health tracking. Updated by Auditor at sprint end.

## Column Definitions

| Column | Meaning |
|--------|---------|
| **Goal Met** | Did the sprint achieve its stated objective? (Y/N) |
| **Delivered** | Number of tasks/features completed vs planned |
| **On Branch** | All work merged to main? (Y/N) |
| **Ctx <50%** | Did workers stay under 50% context window? (Y/N) |
| **Build** | Clean build after merge? (Y/N) |
| **Notes** | Key observations, grade summary |
