# User Decisions Register

Cross-role register of every user decision. Prevents knowledge loss across context clears.

**Rule**: When saving a decision to a topic file (e.g., `memory/design.md`), ALSO add a one-line entry here. This file is the single index of all decisions.

**Superseded decisions**: ~~Strikethrough~~ old decision, add new row with current choice. Never delete — history matters.

### Adding New Decisions

1. Identify the category (Product, Infrastructure, or Harness). Create a new category table if none fits.
2. Assign the next sequential number within that category.
3. Write a concise one-line decision statement (e.g., "Use Stripe for payments, not Mollie").
4. Reference the topic file where the full context lives.
5. Add today's date.
6. If this supersedes an earlier decision, strikethrough the old row.
